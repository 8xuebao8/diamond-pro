- 鼠标或手指拖动旋转，键盘方向键也可旋转；有侧视、俯视、仰视、复位、自动旋转按钮。

- 跟随页面的中文 / English / ไทย 切换。

## 3.0 更新：3D 钻石按输入变形，并可与标准钻石对比（2026-10-26）

- **默认显示标准钻石**，比例为：台宽 57%、冠角 34.5°、腰厚 3%、亭角 40.8°、星刻面 50%、下腰刻面 77%、底尖 None。由此推算冠高约 14.00%、亭深约 43.16%、全深约 60.16%。GIA 只规定 Excellent 区间，没有唯一的“完美”数值；这组常用理想值各项都在课程 EX 区间内，仅用于示意对比。
- **按输入变形**：形状使用以下计算结果：台宽比、冠角、腰厚比、亭深比（换算为亭角；没有亭深时用亭角结果）、星刻面、下腰刻面，以及底尖大小（按描述画成示意大小的底尖小面）。没填或无效的项目暂用标准值，状态行会显示“x/7 项”。数据变化时形状平滑过渡。
- **可绘制范围**：台宽 35–85%、冠角 10–50°、腰厚 0–12%、亭角 30–55°、星刻面 15–90%、下腰刻面 30–95%。超出范围时图形按范围边界绘制并提示，计算与评级仍使用原始数值。
- **“对比标准钻石”按钮**：标准钻石以橙色半透明叠在后面，外轮廓用橙色虚线标出，两颗钻石按同样的腰围直径对齐。按钮下方显示逐项差异表（你的钻石 / 标准钻石 / 差异）；表中“你的钻石”一栏用的是计算区的结果值。
- 验收（本地 HTTP 预览）：测试了偏离标准的完整数据、部分数据（1/7 项）、清空后恢复标准、极端值按范围绘制并提示，以及无效输入不参与变形；测试了 1100 px 和 375 px 宽度与三语切换。除新增的 3D 部分外，其余代码与 2.0github_最终 逐字一致。

## 3.0 更新：标注显示输入数值，腰围改为弯曲波浪边（2026-10-26）

- **标注显示数据**：“测量项目”的 11 个标注在名称下方显示你的数值和等级（例如“64.81% · VG”）。数值和等级颜色来自计算区的同一个结果，与比例图一致；没填写的项目不显示数值。
- **弯曲腰围**：腰围上下边缘由 16 个上腰刻面和 16 个下腰刻面的平面切出，在刻面交界处形成“山”（较厚），在刻面中间形成“谷”（较薄）。真实起伏只有约 0.85% 直径，看不清楚，所以图中按 2 倍放大示意，与原 2D 线稿的波浪画法一致。你输入的腰厚对应谷位（最薄处，与课程“在谷位测量”一致），腰厚尺寸线也画在谷位上。腰围带改为不透明的磨砂质感，并加深上下边线。
- 验收：本地 HTTP 预览下，1100 px 宽度显示全部 11 个带数值的标注；用 2 倍分辨率截图检查了腰围波浪和背面线条；原有代码与 2.0github_最终 逐字一致，脚本语法检查通过。

## 3.0 更新：自动计算值直接采用，名称可多选筛选（2026-10-26）

- **自动计算值直接采用**：网页联动推算的腰厚或亭深、查表得到的冠高或亭角（计算结果中标为 derived / lookup 的值），3D 直接采用，不再使用标准值。另外 3D 自己补充两种推算：冠角未填但冠高为实测时，用冠高和台宽反推冠角；亭深和亭角都没有时，用“全深 − 冠高 − 腰厚”推算亭深。状态行会写明“其中 x 项为自动计算”，差异表中这些值带“自动”标记。只有确实无法得到的项目才用标准值。
- **名称多选筛选**：没有选中任何名称时显示全部标注；点击名称（下方按钮或图中标注）后只显示选中的项目，其他标注和它们的尺寸线一起隐藏。可以多选；再点一次取消该项，全部取消后恢复显示全部。“测量项目”和“刻面与部位”切换时清空选择。
- 手机：没有选中时也显示全部标注，分成钻石上方和下方几排，每个标注显示本地语言名称和数值。
- 验收（本地 HTTP 预览）：测试了腰厚联动 3.2% 被直接采用、冠高实测 14% 反推冠角 34.50°；选择顺序“全部 11 项 → 台面 → 台面 + 冠角 → 冠角 → 全部 11 项”正确，选中后尺寸线从 29 条减为该项的 3 条；手机 375 px 无横向溢出。原有代码与 2.0github_最终 逐字一致。


- 修正（2026-10-26）：鼠标左右拖动方向原先是反的，已改为“抓着钻石转”——向右拖，正面向右转。上下拖动保持不变：向下拖时台面朝你倾斜。

## 3.0 更新：示例数据按钮（2026-10-26）

- “共用测量数据”卡片右上角新增小按钮“示例 / Example / ตัวอย่าง”。点击后填入一组示例：平均直径 3.9 mm、实际重量 0.227 ct、全深 2.3 mm、平均台宽 2.57 mm、平均冠角 36°、平均腰厚 0.01 mm、星刻面 55%、下腰刻面 85%、底尖 Very Small。亭深留空，由网页自动算出 46.32%。

- 已有数据时先弹窗确认，选“取消”则不改动。页面默认仍为空白，只有点击按钮才会填入示例。
- 验收：在空白页填入后完成 9/10 项，亭深自动为 46.32%；先切换到四次台宽和腰厚 % 再点示例，也能切回并正确填入；取消确认后数据保持不变；电脑宽度和手机 375 px（泰文）下按钮位置正常。

- 验收：三个书签都能跳到栏目顶部，高亮随滚动切换，三语名称正确；手机 375 px 无横向溢出。
